Privacy Policy

Applies to the personal Google API integration (omarchy_ayumad)
Operated by Ayush Madhukar · Last updated 10 September 2026

This policy covers a single-user, self-hosted automation tool that I operate for my own Google account. It is not a public product, it has no other users, and it is not offered as a service to anyone else. It connects to Google APIs through OAuth with my explicit consent.

What this tool is

The tool is a personal agent (Hermes Agent) running on hardware I own in my home. The OAuth client is named omarchy_ayumad, and it is authorized only by me, for my own accounts. It automates my own workflows — for example a morning briefing, keeping my task lists in sync, drafting documents I ask for, and searching my own mail and calendar when I ask a question.

Google data it accesses

With my consent, and only for my own accounts, it may read or write:

  • Gmail — read, search, and send mail on my behalf.
  • Google Calendar — read and create events.
  • Google Drive, Docs, Sheets, and Slides — read and create my own files.
  • Contacts — read-only, to resolve names to addresses.
  • Google Tasks — read and update my own task lists.
  • YouTube — read-only viewing history and subscriptions, for personal notes.

How the data is used

Solely to perform the tasks I request of my own agent — summarizing, searching, syncing, and drafting my own content. Nothing is used for advertising, profiling, credit assessment, or any purpose unrelated to a task I initiated.

Where data is stored, and who can see it

  • OAuth tokens and any fetched content are stored locally on hardware I own and control (a machine on my home network) and are not exposed to the public internet.
  • No data is sold, rented, or shared with third parties, and nothing is transferred to advertisers or data brokers.
  • Google API data is not used to train or improve generalized AI models. When I ask my agent to reason over content I requested, that content is processed in transit by the AI model provider I have selected, under its API data-use terms and solely to answer my request.

Google API Services User Data Policy. This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Access can be revoked at any time at myaccount.google.com/permissions. Revoking access immediately invalidates the stored tokens, and the tool stops working.
  • Locally stored data is deleted on request.
  • Google API data is retained only as long as needed for the task at hand.

Children

This is not a public service and is not directed at children. It has one user: its owner.

Changes

Any change to how this tool handles Google user data will be published on this page with an updated date above.
