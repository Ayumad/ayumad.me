Staged learning projects

[!summary] The gist Nine projects, roughly in difficulty order, that build real agent skills: structured output, tool use, memory, evaluation, multi-agent coordination. Each lists the time, difficulty, and the curriculum note behind it. Do them in order and you end with a governed, production-ready system instead of a demo.

  1. Structured assistant (~2 hrs, easy): one model, one schema, no side effects. Test validation and malformed output recovery. See Structured Outputs and Tool Calling.
  2. Tool-calling agent (~3 hrs, easy-moderate): add a read-only calculator or weather tool, typed arguments, timeout, and trace. See Structured Outputs and Tool Calling.
  3. Sandboxed coding loop (~4 hrs, moderate): add temporary files, tests, and a disposable execution plane; require approval before writes outside it. See Sandboxes and Execution Planes.
  4. Evidence-based RAG agent (~5 hrs, moderate): index a small corpus, show citations, test missing and contradictory evidence. See RAG.
  5. Persistent assistant (~4 hrs, moderate): add inspectable semantic and procedural memory with confirmation and deletion. See Memory and Skills.
  6. Orchestrated workflow (~6 hrs, moderate-hard): add queues, retries, checkpoints, and a human handoff around a deterministic pipeline. See Orchestration Hub.
  7. Multi-agent team (~8 hrs, hard): add a supervisor and two bounded specialists with typed handoffs and independent evaluations. See Multi-Agent Systems.
  8. Governed agent democracy (~10 hrs, hard): add proposals, critics, quorum, dissent, reputation decay, audit logs, and a human veto. See Reliability Evals and Observability.
  9. Production capstone (~12 hrs, expert): combine routing, RAG, sandbox, approvals, telemetry, regression tests, budgets, incident response, and a documented rollback. See Deployment and AgentOps.

For every project, record the model, harness, context, tools, state, authority, stop conditions, evaluation set, traces, cost, and known failure modes.
