Arch became my default after starting as a tinkering project. A good opinionated setup on top of it helped me spend more time using the system and less time rebuilding the same defaults.

## What breaks

Things break occasionally. It is usually an incomplete upgrade, a kernel change, a module rebuild, or an external package that needs attention.

1. Finish upgrades instead of postponing them indefinitely.
2. Read package news before changing three configuration files.
3. Check the kernel and module output after a reboot.

The system is not zero-maintenance, but the failures are usually understandable once I stop treating them as random.

## What just works

The daily stuff is boring in the good way: windows tile, the bar starts, suspend works, and the same habits transfer between machines. That consistency is why I keep using it.

The real daily-driver test is whether I reach for it when I do not have to. I do. The occasional repair is a fair trade for a system that feels exactly like mine.
