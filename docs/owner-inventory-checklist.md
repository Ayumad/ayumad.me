# Owner inventory checklist

Internal working checklist for the next gear review. This file is not imported
by the site build and must not be linked from a public route.

Record only the minimum information needed to identify a device and describe
its role. Use neutral unit labels where a product has multiple copies. Do not
record serial numbers, asset tags, account details, license keys, MAC addresses,
IP addresses, hostnames, or other network identifiers.

## Computers

### CHUWI MiniBook X

- [ ] Verify installed memory capacity and whether it is soldered or replaceable.
- [ ] Verify storage capacity and current operating system.
- [ ] Record the verification date and source (physical check or system report).

### Desktop PC (Core i7-9700K)

- [ ] Verify the installed GPU model and VRAM.
- [ ] Record storage and current operating system only if they affect its role.

## Engineering desktop

- [ ] Verify host chassis, CPU, motherboard, and the Radeon RX 6600 board partner.
- [ ] Verify NVMe capacity and operating system state.

- [ ] Confirm the current role and whether the machine is available for use.
